# Pomi's ABC Adventure

Interactive kindergarten alphabet learning adventure based on the supplied Pomi pages.

## Included
- Cover/start page
- ABC story activity with reading timer
- Find the Letter A-E
- Uppercase/lowercase matching
- Letter/picture matching
- Missing-letter sequences
- ABC quick quiz
- Parent Activity Guide
- Achievement page
- Shared navigation, progress bar, responsive layout, and completion tracking

## GitHub Pages
Upload all files in this folder to the root of a GitHub repository, enable GitHub Pages from the repository's Pages settings, and open the published site.

The activity completion state is stored in the browser with localStorage.
